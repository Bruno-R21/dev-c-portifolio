# 💻 Dev C Portfolio

🚀 Repositório dedicado ao estudo da linguagem **C**, com exercícios, algoritmos e projetos práticos de programação.

---

## 📌 Sobre o projeto

🧠 Este repositório tem como objetivo praticar programação em C, focando em:

- 💻 Lógica de programação
- 🔢 Estruturas condicionais e repetição
- 🧾 Funções e modularização
- 📂 Vetores e matrizes
- 🧷 Ponteiros
- 🧱 Estruturas de dados básicas
- 🧮 Resolução de problemas

---

## 🎯 Objetivos

✔ 💻 Fortalecer a base em programação de baixo nível  
✔ 🧠 Desenvolver raciocínio lógico  
✔ 🛠️ Praticar boas práticas em C  
✔ 🚀 Evoluir para estruturas mais avançadas
